
# Online Retail Sales Data Analysis

## Project Overview

This project focuses on analyzing an Online Retail dataset to discover sales trends, customer behavior, product performance, and geographical sales insights.

The goal is to transform raw retail data into meaningful business insights using Python, SQL Server, and Power BI.

## Project Objectives

- Analyze overall retail sales performance.
- Identify top-performing products and countries.
- Understand customer purchasing behavior.
- Examine monthly sales trends.
- Analyze returned products and quantities.
- Build an interactive sales dashboard.

## Tools & Technologies

- Python
- Pandas
- SQL Server
- Microsoft Power BI
- DAX
- Data Cleaning
- Data Visualization

## Project Workflow

### 1. Data Cleaning – Python

- Explored the original dataset.
- Identified missing and invalid values.
- Cleaned and prepared the dataset using Pandas.
- Exported the cleaned dataset for further analysis.

### 2. Data Analysis – SQL Server

- Analyzed total records and unique customers.
- Examined invoice and revenue performance.
- Identified top products and countries.
- Analyzed customer spending and purchasing behavior.
- Investigated returned quantities.
- Created SQL queries to answer business questions.

### 3. Data Visualization – Power BI

Built a sales dashboard containing:

- Total Revenue
- Total Orders
- Total Customers
- Total Quantity Sold
- Returned Quantity
- Average Order Value
- Monthly Revenue Trend
- Top 10 Products by Revenue
- Top 10 Countries by Revenue
